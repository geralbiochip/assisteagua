Résultats de la vérification documentée

Les informations reposent sur l’examen du code fourni et des captures d’une vérification manuelle dans Chrome le 12 novembre 2026. Les tableaux observés pour https://geralbiochip.github.io ne montraient aucun cookie ni entrée de Local Storage ou Session Storage.

  • Cookies : aucune entrée répertoriée dans les captures fournies, avant et après la navigation documentée.
  • Local Storage : aucune entrée répertoriée dans la capture fournie.
  • Session Storage : aucune entrée répertoriée dans la capture fournie.

Le résultat concerne l’origine sélectionnée et les moments documentés. Il ne constitue ni une surveillance continue ni l’observation de toutes les réponses des prestataires externes.

Aucun cookie n’apparaissant dans ces captures, aucun nom ou délai d’expiration observé ne peut être présenté dans ce relevé. L’examen du code n’a pas identifié les outils d’analyse ou de publicité recherchés.
