Serviços externos identificados

GitHub Pages

O GitHub Pages é utilizado para publicar o site. O acesso ao alojamento envolve comunicações técnicas necessárias à entrega das páginas; a ausência de cookies observados não significa ausência de tratamento de dados técnicos.

Formspree

O Formspree é utilizado para receber os pedidos do formulário de contacto. O envio comunica os campos preenchidos ao prestador para processar o pedido.
